# V5 — Reliable processing

## Goal
Make repeated delivery boring.

## Prerequisites
Idempotency, ordering, retries, dead letters; complete V4.

## Lessons
Add inbox, dedupe, sequence policy, dead letter.

## Implementation tasks
1. Write a design note before code.
2. Keep external inputs behind a boundary.
3. Add a credential-free fixture or test.
4. Update diagrams/ADRs when boundaries change.
5. Label incomplete work honestly.

## Lab
Process-once and projection rebuild.

## Failure injection
Duplicate, out-of-order, poison, transient failure.

## Acceptance criteria
Two runs produce one projection and audit trail.

## Checkpoint questions
