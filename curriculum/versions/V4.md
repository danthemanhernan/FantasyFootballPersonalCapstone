# V4 — Live ingestion

## Goal
Convert play payloads to canonical events.

## Prerequisites
Polling, normalization, identity, replay; complete V3.

## Lessons
Define cursor, game/play identity, raw fixture.

## Implementation tasks
1. Write a design note before code.
2. Keep external inputs behind a boundary.
3. Add a credential-free fixture or test.
4. Update diagrams/ADRs when boundaries change.
5. Label incomplete work honestly.

## Lab
Deterministic replay and bounded polling.

## Failure injection
Repeated page, cursor gap, unknown player.

## Acceptance criteria
Repeatable replay with source metadata.

## Checkpoint questions
What makes replay safe?

## Stretch goal
Second provider fixture.

## Further reading placeholders

## Status
Implemented as an offline deterministic replay lab. Raw fixtures are validated,
normalized into versioned canonical events, and tested for cursor gaps,
unknown identities, malformed values, duplicate IDs, and repeatable output.
Live polling, persistence, idempotent processing, ordering reconciliation,
pagination, and a production play-by-play contract remain deferred.
