# V3 — Fantasy provider

## Goal
Load roster without provider leakage.

## Prerequisites
HTTP, DTOs, adapters, rate limits; complete V2.

## Lessons
Define provider port and canonical models.

## Implementation tasks
1. Write a design note before code.
2. Keep external inputs behind a boundary.
3. Add a credential-free fixture or test.
4. Update diagrams/ADRs when boundaries change.
5. Label incomplete work honestly.

## Lab
Fixture adapter then timeout-bounded client.

## Failure injection
429, 404, malformed JSON, renamed field.

## Acceptance criteria
Offline tests and classified errors.

## Checkpoint questions
Where do retries live?

## Stretch goal
