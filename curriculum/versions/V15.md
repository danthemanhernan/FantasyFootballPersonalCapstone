# V15 — Player and official detection

## Goal

Select a detector using football-specific evidence instead of headline COCO
scores.

## Prerequisites

V13 corpus and V14 scene gate.

## Implementation tasks

1. Establish a YOLO26n/s baseline for player and official classes.
2. Compare at least one alternative size or architecture under identical input,
   hardware, and runtime conditions.
3. Tune confidence thresholds on validation data only.
4. Export timestamped detections through the V12 contract.
5. Slice errors by shot, box size, crowding, occlusion, and class.
6. Complete the vision decision rubric and retain hard examples.

## Required artifacts

- Reproducible training/inference configuration
- Detection JSONL and rendered diagnostic video
- Precision–recall curves and sliced evaluation report
- Detector decision record

## Metrics

Precision, recall, F1, AP50–95, AP-S, wide-shot recall, crowded-scene recall,
player/official confusion, false positives per minute, p95 inference latency,
and peak memory.

## Failure injection

Sideline crowds, officials, fans, replay graphics, motion blur, pile-ups, tiny
players, and partial bodies at frame boundaries.

## Acceptance criteria

The detector passes resource and latency gates and has no hidden critical slice
failure. Selection is justified by project metrics, not one aggregate score.
