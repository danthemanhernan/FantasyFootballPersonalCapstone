# V13 — Authorized evaluation corpus

## Goal

Create a small, legally usable, versioned football-video corpus that can reveal
whether a model generalizes across games and broadcast conditions.

## Prerequisites

V12 contracts and artifact policy.

## Implementation tasks

1. Acquire licensed, self-recorded, or otherwise authorized clips.
2. Define annotation guidance for players, officials, boxes, track IDs,
   occlusion, shot type, camera cuts, team, jersey visibility, and `unknown`.
3. Split data by game or recording session—not random frames.
4. Build dataset manifests with checksums, provenance, rights, and split names.
5. Measure annotation agreement on a shared sample and resolve disagreements.
6. Add a validator for invalid boxes, duplicate IDs, split leakage, and timestamp
   errors.

## Required artifacts

- Annotation handbook
- Dataset and split manifests with checksums
- Dataset validator and distribution report
- Rights/provenance record

## Metrics

Labeled player-seconds, box-size and occlusion distributions, shot coverage,
jersey-visible coverage, annotation agreement, and split-leakage checks.

## Failure injection

Duplicate a clip across train and test, corrupt an annotation, omit rights
metadata, and introduce inconsistent track IDs.

## Acceptance criteria

Another developer can reconstruct the same permitted corpus and splits from the
manifest, validate it, and obtain the same distribution report.

## Status

Not started. No model comparison is valid before this milestone.
