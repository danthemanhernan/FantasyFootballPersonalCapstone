# V17 — Field geometry and overlay coordinates

## Goal

Transform model-space tracks into stable screen-space markers while accounting
for letterboxing, resizing, camera motion, and optional field geometry.

## Prerequisites

V14 scene IDs and V16 tracks.

## Implementation tasks

1. Make source, decoded, model, field, viewport, and CSS transforms explicit.
2. Establish field-line/keypoint and homography experiments for usable shots.
3. Estimate camera motion and compare it with track motion.
4. Define marker anchors for standing, crouched, and partial players.
5. Add smoothing with bounded lag and immediate reset behavior.

## Required artifacts

- Coordinate-transform library and property tests
- Geometry debug overlay
- Anchor-error and jitter report
- Fullscreen, resize, and letterbox browser fixtures

## Metrics

Normalized anchor error, reprojection error, marker jitter, smoothing delay,
off-screen marker rate, stale-marker duration, and transform round-trip error.

## Failure injection

Aspect-ratio changes, fullscreen, browser zoom, black bars, digital crops,
camera zoom, unstable homography, and abrupt cuts.

## Acceptance criteria

Markers remain aligned through supported layout changes. Geometry failure falls
back to box-relative placement or no marker rather than a displaced identity.
