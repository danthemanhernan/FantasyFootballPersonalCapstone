# V2 — Local persistence

## Goal
Reload without losing state.

## Prerequisites
Schemas, migrations, browser storage; complete V1.

## Lessons
Version snapshot and migration.

## Implementation tasks
1. Write a design note before code.
2. Keep external inputs behind a boundary.
3. Add a credential-free fixture or test.
4. Update diagrams/ADRs when boundaries change.
5. Label incomplete work honestly.

## Lab
Persist settings and cursor behind an interface.

## Failure injection
Corrupt JSON; downgrade; quota failure.

## Acceptance criteria
Valid restore; invalid state quarantined.
