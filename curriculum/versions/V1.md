# V1 — Scoring domain

## Goal
Separate configurable scoring from UI.

## Prerequisites
Pure functions, invariants, tests; complete V0.

## Lessons
Define league settings, stats, breakdown, examples.

## Implementation tasks
1. Write a design note before code.
2. Keep external inputs behind a boundary.
3. Add a credential-free fixture or test.
4. Update diagrams/ADRs when boundaries change.
5. Label incomplete work honestly.

## Lab
Table-driven scoring for yardage, receptions, TDs, turnovers.

## Failure injection
Missing stats, negative yardage, duplicates.

## Acceptance criteria
Deterministic tests reconcile deltas to totals.

## Checkpoint questions
What is an invariant?

## Stretch goal
Property-based tests.

## Further reading placeholders
Official docs; one design paper; one postmortem; one experiment note.

## Status
