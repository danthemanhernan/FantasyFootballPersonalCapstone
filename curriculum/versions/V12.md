# V12 — Vision contract and safety gates

## Goal

Turn “identify players on a broadcast” into explicit contracts, measurable
failure budgets, and reproducible experiment interfaces before selecting a
model.

## Prerequisites

Operational telemetry from V9; read the vision design, model comparison,
decision rubric, and metrics cheat sheet.

## Implementation tasks

1. Define frame, detection, track, evidence, identity-belief, and marker schemas.
2. Define coordinate spaces and required timestamps at every stage.
3. Freeze hard gates for false identities, latency, queue growth, resource use,
   broadcast cuts, licensing, and abstention.
4. Create an experiment manifest containing Git commit, dataset version, model,
   runtime, hardware, configuration, and random seeds.
5. Write an authorized-input and artifact-retention policy.
6. Create a no-model fixture that passes synthetic records through every
   contract.

## Required artifacts

- Versioned JSON schemas or typed models
- Example experiment manifest
- Coordinate-system diagram
- Safety-gate decision record
- Credential-free fixture and contract tests

## Failure injection

Malformed boxes, non-monotonic timestamps, unknown model version, impossible
coordinates, missing evidence, and a forced identity with no abstention path.

## Acceptance criteria

Every later stage can consume and emit versioned records without importing a
specific model framework. The rubric's hard gates are machine-readable or
represented by executable assertions.

## Checkpoint questions

- Which failures must suppress a marker?
- Which timestamps are required to calculate true capture-to-overlay latency?
- What evidence must be retained to reproduce one identity decision?

## Status

Not started. This milestone produces contracts, not a trained model.
