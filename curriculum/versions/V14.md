# V14 — Broadcast scene and camera-cut gate

## Goal

Process only useful field views and reset temporal state when the broadcast
changes scenes.

## Prerequisites

V13 corpus with shot-type and camera-cut annotations.

## Implementation tasks

1. Establish histogram or feature-distance baselines for cut detection.
2. Classify wide field, medium field, close-up, replay, sideline, studio,
   commercial, and graphic-dominant shots.
3. Emit scene IDs and explicit reset events.
4. Measure cut-to-reset latency and stale-state duration.
5. Define which shots permit detection, jersey recognition, or no overlay.

## Required artifacts

- Scene-gate module and CLI
- Timeline visualization for at least one complete drive
- Shot confusion matrix and cut/reset report

## Metrics

Cut precision/recall, shot macro-F1, stale-state duration, cut-reset p95 latency,
and percentage of useful player-visible time retained.

## Failure injection

Dissolves, slow-motion replays, scoreboard animations, picture-in-picture,
rapid cuts, and a missed cut with active tracks.

## Acceptance criteria

Stale tracks cannot cross a detected scene boundary, and useful field footage is
not discarded beyond its predeclared recall budget.

Not started.
