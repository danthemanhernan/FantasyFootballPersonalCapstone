# Curriculum

Sprint 0 remains the first runnable checkpoint. The backend and product platform
progress through V0–V11. The real-time vision curriculum continues through
V12–V25, with one measurable subsystem introduced per version.

Suggested pacing: weeks 1–3 V0–V2; 4–7 V3–V5; 8–11 V6–V8; 12–16 V9–V11.
Treat V12–V25 as an experiment-driven sequence rather than a calendar plan.
Advance only when the current milestone's acceptance evidence is reproducible.

Learning modules cover browser extensions, HTTP/APIs, domain modeling, async Python/WebSockets, message brokers, distributed systems/idempotency, data modeling, probability/Monte Carlo, ML/calibration, observability/delivery, and real-time detection/tracking/identity systems.
