# Curriculum

Sprint 0 remains the first runnable checkpoint. Then work through curriculum/versions/V0.md through V12.md.

Suggested pacing: weeks 1–3 V0–V2; 4–7 V3–V5; 8–11 V6–V8; 12–16 V9–V10; 17–20+ V11–V12. The course is milestone-based, not calendar-based.

Learning modules cover browser extensions, HTTP/APIs, domain modeling, async Python/WebSockets, message brokers, distributed systems/idempotency, data modeling, probability/Monte Carlo, ML/calibration, observability/delivery, and vision/tracking/OCR.
