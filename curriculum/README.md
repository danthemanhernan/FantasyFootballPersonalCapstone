# Fantasy Football HUD curriculum

This capstone is a sequence of engineering problems. Every milestone has a product outcome, a concept to learn, a small implementation exercise, and a reflection question.

- [Sprint 0](sprint-0.md): Establish a runnable vertical slice.
- Sprint 1: Make fantasy scoring a tested domain module.
- Sprint 2: Persist lineups and settings in Chrome storage.
- Sprint 3: Integrate a fantasy platform API safely.
- Sprint 4: Normalize live play-by-play data.
- Sprint 5: Make event processing reliable.
- Sprint 6: Add a backend service and database.
- Sprint 7: Replace polling with live updates.
- Sprint 8: Support leagues, matchups, and identity.
- Sprint 9: Deploy with CI/CD and observability.
- Sprint 10: Add analytics and projections.
- Sprint 11: Test scale, resilience, and backpressure.
- Sprint 12: Polish the broadcast-ready experience.

A good learning loop is: predict, implement, observe, explain, and write down the next constraint.
