Key rule: await pauses the current task. A blocking call pauses the event-loop thread.

What happens at await?

1. Task runs
Python executes until it reaches an awaitable.
→
2. Task yields
The event loop records what it is waiting for.
→
3. Other work runs
Another ready task gets the worker.
→
4. Task resumes
The result arrives and execution continues.
