# Trim6 silver v0.1 validation and baseline

`trim6-silver-v0.1` is the first manually corrected CVAT export of the
18-second `trim6-golden-30s-48s.mp4` broadcast clip. It is suitable for lab
iteration and targeted fine-tuning, but it is not yet an independently audited
gold dataset.

The recorded shot ranges are frames 0–8, 9–123, and 124–539. No identity
currently crosses one of those camera cuts.

## Targeted review queue

Seven tracks have repeated visible/outside transitions that deserve another
CVAT pass:

| Track | Label | Frame span | Visible frames | Review reason |
|---:|---|---:|---:|---|
| 38 | player | 354–494 | 89 | 16 internal gaps, including a long gap |
| 50 | player | 371–477 | 88 | 7 internal gaps |
| 55 | player | 379–441 | 59 | repeated alternating-frame gaps |
| 83 | player | 442–466 | 22 | gaps at frames 455, 459, and 463 |
| 120 | sideline_person | 502–538 | 34 | gaps at frames 506, 512, and 520 |
| 133 | player | 9–123 | 97 | 9 internal gaps |
| 158 | player | 124–323 | 190 | 6 internal gaps |

An internal gap can be correct when a person is fully occluded. The review
decision is whether the same person remains present and should be interpolated,
or whether the first track should end and a new track should begin.

Team attributes are not ready for supervised use: 7,407 player boxes remain
`team=unknown`, compared with 136 `home` and 102 `away`. `jersey_visible` is
`false` on all 7,645 player boxes. These fields can be ignored for the initial
player detector, but should not be treated as training labels yet.

## YOLO26n + BoT-SORT diagnostic

Results at IoU 0.50:

| Metric | Result |
|---|---:|
| Precision | 94.4% |
| Recall | 74.9% |
| F1 | 83.5% |
| Player recall | 71.8% |
| False negatives | 2,159 |
| Unmatched predictions | 381 |
| Approximate ID switches | 14 |
| Identities fragmented across predicted tracks | 9 |

These are diagnostic figures, not unbiased benchmark scores. The initial boxes
were generated by this same baseline, which explains the 0.995 mean matched IoU
and inflates precision. Recall is directionally useful because the manual pass
added missed people, but model selection needs a different clip annotated
without imported predictions.

## Next quality gate

1. Review the seven flagged tracks and export `trim6-silver-v0.2`.
2. Set `home`/`away` only where the team is visually reliable.
3. Independently annotate a different 15–30 second clip as a holdout.
4. Fine-tune on the silver training data, but select models using the holdout.
5. Add HOTA, AssA, DetA, and IDF1 after the holdout identities receive a second
   consistency pass.
