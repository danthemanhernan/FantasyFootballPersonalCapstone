# ADR-002: Monorepo boundaries

- Status: Accepted
- Date: 2026-08-12

The extension, services, schemas, simulations, and learning material change in lockstep. Keep one repository with explicit apps, services, packages, simulation, infra, ml, docs, learning, and curriculum boundaries. Revisit when measured build time, ownership, release cadence, or access control proves this is the bottleneck.
