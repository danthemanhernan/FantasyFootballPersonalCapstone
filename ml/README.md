# ml

This boundary holds experiment code and artifacts introduced by the granular
vision roadmap:

- V12–V13: contracts, manifests, dataset tooling, and annotations
- V14–V17: scene gating, detection, tracking, and geometry
- V18–V21: team, jersey, and calibrated identity evidence
- V22–V25: optimized runtime, integration, live shadow evaluation, and model ops

Add implementation only when its milestone creates a measurable need. Model
weights, licensed footage, generated videos, and large datasets must stay out of
Git. Commit configuration, small fixtures, schemas, evaluation summaries, and
reproduction instructions instead.
